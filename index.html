QUEST 08

            
A parser accepts a declared length and a payload. The proposed patch checks only that the declaration is at most eight. Inspect what it misses before choosing the safer candidate.

            

              
Vulnerable parser

Candidate A · incomplete
if (declared <= 8)
    copy_bytes(buffer, payload, declared);

              
Candidate B · compare both lengths
if (declared <= 8 && declared == payload_bytes)
    copy_bytes(buffer, payload, declared);
