WHAT TO NOTICE

The boundary is a rule in code.

Memory is just numbered byte-sized boxes. A fixed buffer has an end; an unchecked copy can keep writing past it.

THE TAKEAWAY

Check the input length before copying. A single boundary check protects the neighboring value.
